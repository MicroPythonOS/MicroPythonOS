# Apps preinstalled into the device filesystem image and the web bundle.
#
# One app per line:
#   repo     <fullname> [target=device|web]
#   badgehub <fullname> [version=<v>] [sha256=<hex>] [target=device|web]
#
# "repo" apps come from internal_filesystem/apps/<fullname> in this checkout.
# "badgehub" apps are downloaded from badgehub.eu (the same channel the
# AppStore uses). Without version=/sha256= the latest published version is
# used, so a release image always ships the newest BadgeHub build.
#
# target= stages the app only for that target; without it the app ships in
# both the device image and the browser bundle.
#
# Keep this list small: every entry costs flash space in the 7 MB badge
# filesystem. Precompiled to .mpy these are roughly 500 KiB together.
